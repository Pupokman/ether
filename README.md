# Iris Vulkan 26.3 (experimental)

Experimental Vulkan backend work for Iris 1.11.6 / Minecraft 26.3.

Goals:
- Minecraft native Vulkan backend
- Sodium 0.9.x compatibility
- existing Iris/OptiFine shaderpack compatibility
- Distant Horizons 3.3.x integration through its Blaze/RenderPearl renderer

This repository is development-only for now. Do not treat builds as release-ready.
